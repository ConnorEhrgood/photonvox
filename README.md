# PhotonVox

Photon's phone system (formerly Photon PBX): voice, texting and team chat for Photon's customers and partners, built around a FreeSWITCH +
FusionPBX engine, signed in with PhotonID, monitored by PhotonConsole.

**State (2026-11-13):** design only. The engine runs in production in the colo (FusionPBX, LXC 600); this repo holds the plan for the
product around it.

- [docs/ARCHITECTURE.md](docs/ARCHITECTURE.md): the design, with the decisions waiting for Connor at the top.
- [docs/BUILD-GUIDE.md](docs/BUILD-GUIDE.md): the build in steps with gates.
- [docs/BUILD-LOG.md](docs/BUILD-LOG.md): dated notes.
